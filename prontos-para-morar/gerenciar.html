O que é a URL do GAS? É o endereço do seu Google Apps Script configurado como "web app" — ele salva leads e envios numa planilha Google. Se já usa o painel BASE INTELIGENTE, copie o valor de painel/config.js → campo gUrl. Se não tiver, deixe em branco — os dados chegam pelo WhatsApp normalmente.
